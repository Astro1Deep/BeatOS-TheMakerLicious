BeatOS 3.8.0 is a sample library and 16-pad beatmaking workstation with destination-specific exports for Akai MPC, NI Maschine, Roland SP-404 and Teenage Engineering samplers. The documentation explains the difference between generating files and proving device/firmware compatibility.

The English manual covers the full user workflow. Topic navigation is also available through [English wiki home](../wiki/Home_EN.md). Some browser controls and command-line messages remain only partially localized while testing continues; this does not change the language of your audio files or project titles.
