# Organización de la biblioteca, discos y tarjetas

[Manual completo: bibliotecas y archivos](../MANUAL_COMPLETO.md#3-bibliotecas-rutas-y-archivos)

La raíz de una biblioteca organizada contiene dos accesos HTML y la carpeta BeatOS del sistema. Las carpetas de música existentes conservan su ubicación para mantener referencias de programas y proyectos. No es obligatorio renombrarlas ni usar macro-categorías concretas.

BeatOS guarda código e instalador en BeatOS/, índices y catálogo único en BeatOS/data/, preferencias en BeatOS/config/ y recursos en BeatOS/docs/. Los kits nuevos quedan en Custom_Kits/. Las antiguas carpetas SQLITE_DATABASE y _INDEX_MPC_SAMPLE no se crean al indexar. Véase [estructura actual](../ESTRUCTURA_BIBLIOTECA.md).

Antes de retirar una instalación anterior, respalda la base y los archivos de código y conserva las referencias musicales. No restaures backups antiguos encima de una entrega nueva ni ejecutes scripts heredados de reparación para ordenar directorios.
