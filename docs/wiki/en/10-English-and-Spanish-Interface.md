# English and Spanish localization in BeatOS

**BeatOS 3.8.0 · English** · [Español / Versión española](../10-Manual-Bilingue-y-Selector-de-Idioma-(ES-EN).md) · [Complete English manual](../../en/MANUAL_COMPLETO.md#16-language-themes-and-support) · [Hardware compatibility](../../en/COMPATIBILIDAD_HARDWARE.md)

Use the ES/EN button in the header. The choice is saved in the browser's `mpc_lang` preference and recovered the next time you open the interface. The current localization module provides translated menu labels, filters, warnings, tooltips and selected dynamically generated messages; **sample filenames and private paths are not translated**. Some secondary messages and the console output of supporting Python processes may remain in Spanish. The installer itself supports `--lang en` and the environment variable `BEATOS_LANG=en`; its selection is independent of the web UI preference. Decorative themes are not hardware export modes. For the full user workflow, consult the English manual, and report any leftover Spanish phrase together with its screen and operation.
