# Browsing MPC expansions, XPM programs and samples

**BeatOS 3.8.0 · English** · [Español / Versión española](../05-Expansiones-Oficiales-Akai.md) · [Complete English manual](../../en/MANUAL_COMPLETO.md#9-mpc-expansions) · [Hardware compatibility](../../en/COMPATIBILIDAD_HARDWARE.md)

The expansion browser reads available `Expansion.xml` metadata, lists nested program files and indexed XPJ projects, previews samples and can load an eligible **Drum XPM** as a copy in the rack. Keygroup programs still require the real MPC engine. **View projects** scopes the list to the exact expansion directory; **View all** removes that filter. After changing files on disk, **reindex** the library, then refresh the full browser when appropriate. Loading an expansion does not install commercial audio packs, execute native MPC plugins or turn BeatOS into a full expansion playback engine. The export route uses the currently visible 16 pads and must be checked on the destination device.
