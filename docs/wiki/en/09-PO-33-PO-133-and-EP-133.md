# Teenage Engineering sample reels, backups and EP-133 transfers

**BeatOS 3.8.0 · English** · [Español / Versión española](../09-Pocket-Operator-PO-33-KO-Studio-y-FSK-Modem.md) · [Complete English manual](../../en/MANUAL_COMPLETO.md#12-pocket-operator-backup-wavs) · [Hardware compatibility](../../en/COMPATIBILIDAD_HARDWARE.md)

The **PO-33/PO-133 sample reel** concatenates rack pads into **mono 16-bit/44.1 kHz** audio for recording through LINE IN; set an honest **1–40 s** free-memory budget and **0–500 ms** gaps. BeatOS may shorten samples with fade-out to fit and produces slice timings; it does not transfer pan/mute groups or patterns. **PO full-state backup** is a different **stereo audio-data recording** from the PO itself: BeatOS can capture, import, archive, hash and prepare playback of its original WAV but **cannot decode or verify modem content**. Restoring a backup erases the current PO sounds and patterns; make a verified separate copy first. The **EP-133 K.O. II** exporter writes 16-bit/44.1 kHz WAVs, a JSON key/parameter map and ZIP; use the manufacturer's **EP Sample Tool** in a compatible desktop Web MIDI browser. BeatOS does not upload a native EP project; map and adjust sounds manually.
